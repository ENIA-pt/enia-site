05 / 07

O caso que Portugal deve ler

A Finlândia foi o primeiro Estado-Membro com enforcement plenamente operacional (TRAFICOM, janeiro de 2026). Não o fez para «cumprir uma obrigação europeia» — fê-lo para se tornar o país onde qualquer empresa que queira operar IA com segurança jurídica escolhe instalar-se.

Mas os novos prazos alterados pelo Digital Omnibus dão uma segunda oportunidade a Portugal para recuperar o atraso.

Ficar para trás é uma escolha.
Nós somos a outra!

  1. Portugal usa IA acima da média europeia, mas regula abaixo dela. Esse desalinhamento é o risco.

  2. A maioria das PME não tem sequer inventário dos sistemas de IA que usa. Não se protege o que não se conhece.

  3. Compliance não é burocracia. É o bilhete de entrada nos contratos públicos europeus.

  4. Quem construir primeiro a infraestrutura de confiança fica com o mercado. A Finlândia já percebeu. Portugal ainda vai a tempo.
